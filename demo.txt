-------------------------------------------------
  ขั้นตอนการสาธิตที่แนะนำ
-------------------------------------------------

[ลำดับที่ 1] ลูกค้าสั่งอาหาร (Customer Flow)
  1. Login เป็น customer → เลือกโต๊ะ 1
  2. กด "เชิญเพื่อน" → ได้ invite code
  3. กด "สั่งอาหาร" → เลือก 2-3 เมนู → ยืนยันส่งครัว
  4. เห็นรายการอาหาร + ยอดเงินที่ /my-table

[ลำดับที่ 2] เพื่อนเข้าร่วมโต๊ะ (Invite Flow)
  1. สมัครสมาชิกใหม่ หรือ login คนละ browser (Incognito)
  2. ไปที่ "เข้าร่วมโต๊ะ" → ใส่ invite code จากข้อ 1
  3. เห็นโต๊ะเดียวกัน + สั่งอาหารได้

[ลำดับที่ 3] พนักงานครัว (KDS Flow)
  1. Login เป็น staff → คลิก "ครัว (KDS)"
  2. เห็นออเดอร์ที่ลูกค้าสั่ง → กด "เริ่มปรุง" → กด "เสิร์ฟ"

[ลำดับที่ 4] เช็คบิล (Billing Flow)
  1. Login เป็น staff → คลิกโต๊ะ 1 → "เรียกเช็คบิล"
  2. กด "ไปหน้าคิดเงิน" → ใส่ส่วนลด 10% → "ยืนยันรับเงิน"
  3. เห็นยอดคำนวณ: Subtotal - Discount + Service 10% + VAT 7%

[ลำดับที่ 5] ผู้จัดการ (Admin Flow)
  1. Login เป็น admin → "จัดการเมนู"
  2. เพิ่ม/แก้ไข/ลบ เมนู + เปิด-ปิดสถานะ "หมด"
  3. ไป "Dashboard" → ดูยอดขายวันนี้ + กราฟ
  4. ไป "Audit Log" → ดูประวัติการทำงานทั้งหมด
